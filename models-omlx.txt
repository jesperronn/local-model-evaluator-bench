# Models for the oMLX runtime — bench these with: bin/bench --runtime omlx
#
# Ids are the model directory basename under $OMLX_MODELS_DIR (~/.omlx/models),
# which is exactly what oMLX returns from /v1/models. List them with:
#   bin/omlx models
#
# Unlike models.txt (lms) this file is a *curation*, not an inventory: oMLX
# serves everything under its model dir whether or not it is listed here. This
# file only decides what a bare `bin/bench --runtime omlx` runs. To add a model,
# drop it under $OMLX_MODELS_DIR/<org>/<name>, run `bin/omlx reload`, then add
# the basename here.
#
# oMLX loads on first request and evicts LRU, so no manual start/stop per model
# (contrast models-mlx.txt, where mlx_lm.server serves one model per process).
