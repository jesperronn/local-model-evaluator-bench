# AGENTS.md

Each numbered folder is one independent task. Work in one folder at a time.

1. Read `TASK.md` in the current folder — it's the only spec.
2. Edit only the files it names. Keep exported names exactly as given.
3. If the folder has a `package.json`: run `npm test` after editing, and keep
   fixing until it passes. If it has `test.sh`: run `./test.sh` instead.
4. No new dependencies. No new files unless `TASK.md` asks for one.
5. Stop once tests pass (or, if there's no test, once the examples in
   `TASK.md` check out).
